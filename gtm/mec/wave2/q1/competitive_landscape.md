## ⚠️ Corrects what I told Shahwaz on 14–15 Sept

I said twice that generating an original pattern from a plain-language
description was the part **nobody else does**, and that MEC would be
"competing where it's actually alone."

**That was wrong.** Mozaico, a mosaic company, already ships exactly that.

## Tier 1 — direct, same product, same mechanic

**Mozaico — `mozaico.com/pages/ai-mosaic-generator`**
The closest competitor found anywhere. Their own flow:
1. type any text in plain English into a prompt box
2. the AI returns **four** options
3. pick one, send the size
4. they return a **sketch** to visualise the personalised mosaic
5. size drives an automatic price, and the custom design goes **into the cart**

They also run a separate **AI Mosaic Visualizer** for seeing designs in your
own room. And they handle the credibility problem well: the page states the
finished handcrafted mosaic has finer detail, richer texture and greater
artistic depth than the AI preview — so the AI image is positioned as a
preview of handmade work, not a substitute for it.

That is MEC's entire proposition end to end, plus the commerce step MEC does
not have.

**Daltile — four separate tools** (Mohawk, the largest player in the vertical)
- `Stylizer` — upload a photo, see tile in your room
- `Stylizer AI` — pick Modern Farmhouse, Art Deco or Scandinavian and it
  generates curated looks, with a **regenerate** button
- `Mosaic Design Tool` — craft **original** designs or start from templates,
  using Keystones or Color Wheel mosaics; save, print, share, then "Route to
  Location Near Me" to a dealer
- `Pattern Tool` — custom tile pattern layouts

**Marazzi USA** — `Stylizer` and `Stylizer AI`, same Mohawk stack.
**Appiani / Gruppo Bardelli** — `MyCustom` turns any image or graphic into a
custom ceramic mosaic; plus `MyMix` and `MyDegradè`.

## What this means for §7.9 copy

1. **"AI visualiser" is table stakes.** Free tools exist, Mohawk gives one
   away, and a quarter of our own prospect list already has one.
2. **"Describe it and we design it" is no longer unique either.** Mozaico
   shipped it in the exact same niche.
3. So the differentiator cannot be the *feature*. What is left is plausibly:
   - **the prospect's own catalogue and glazes**, not a generic model — a tool
     that composes from *their* 500 glazes and *their* shapes, which no
     horizontal vendor can do and Mozaico only does for itself
   - **embedded on the prospect's own domain** under their brand, so the lead
     stays theirs — the §7.4 pivot angle
   - **the approval artefact**, not the picture: the 17 MANUAL rows lose staff
     time to CAD drawings, sample books and glaze trials. Mozaico's tool sells
     Mozaico's mosaics; it does nothing for McIntyre's glaze-matching loop
4. **Do not lead with "AI".** Every competitor does. Lead with the wait that
   disappears.
5. **Honest-proof rule still binds.** MEC's case study has no hard numbers,
   and now the category has well-funded incumbents. A working link is still
   the strongest asset, but it is no longer a rare one.
